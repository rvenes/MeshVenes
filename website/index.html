Install MeshVenes with PowerShell

Open PowerShell as your normal Windows user. Download and inspect the script, then run it to install MeshVenes and add a Start menu shortcut. No administrator rights or separate .NET installation are needed.

$installer = Join-Path $env:TEMP ('MeshVenes-install-' + [guid]::NewGuid().ToString('N') + '.ps1')
Invoke-WebRequest -UseBasicParsing -Uri https://venes.org/meshvenes/install-windows.ps1 -OutFile $installer -ErrorAction Stop
# Inspect the downloaded script before running it.
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $installer

Read the installer · Review installer source

Close MeshVenes first. Add -DesktopShortcut for a desktop icon. Running the installer again checks the latest release; -Rollback selects the previous installation. Settings and logs are retained.

The installer checks signed release metadata, the ZIP's size and SHA-256 before activation. The application and PowerShell script are not Authenticode-signed. Windows 10 version 2004 or later, x64, is required; supported Windows 11 is recommended. Maps require Microsoft Edge WebView2 Runtime.

Configuration exports are encrypted by default. Local archives are protected for your Windows account; export data you need before reinstalling Windows. Older MeshVenes versions cannot read the new protected archives.

Prefer a portable copy? Download the ZIP, extract it to a writable folder and run MeshVenes.exe.
